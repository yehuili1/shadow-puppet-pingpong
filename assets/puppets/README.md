# 皮影部件贴图：用 PNG 替换代码绘制

默认情况下，`src/puppet/art.js` 用代码画出全部皮影部件（2 个角色 × 2 种风格 × 9 个部件）。
美工出图后，在本目录放 PNG，并在 `manifest.json` 里登记，就能逐个部件覆盖代码绘制。
没登记、文件缺失或加载失败的部件会静默回退到代码绘制，所以可以一次只换一个部件。

## manifest.json

默认是 `{}`（全部用代码绘制）。结构是 `角色 → 风格 → 部件 → { src, ox, oy, s }`：

```json
{
  "hero": {
    "shadow": {
      "torso": { "src": "hero/shadow/torso.png", "ox": 132, "oy": 432, "s": 0.5 },
      "head":  { "src": "hero/shadow/head.png",  "ox": 336, "oy": 640, "s": 0.5 }
    }
  },
  "rival": {
    "color": {
      "tongue": { "src": "rival/color/tongue.png", "ox": 10, "oy": 20, "s": 0.5 }
    }
  }
}
```

| 字段 | 含义 |
|---|---|
| `src` | PNG 路径，相对本目录（`assets/puppets/`）。建议 `角色/风格/部件.png` |
| `ox`,`oy` | 关节枢轴在 PNG 里的像素坐标（左上角为原点）。必须准确，否则拼装时会错位 |
| `s` | 贴图像素 → 世界单位的缩放。按 2 倍分辨率出图就填 `0.5`（默认值） |

- 角色：`hero`（玩家，生角/武将，高冠 + 雉鸡翎，空脸）、`rival`（电脑，净角，背后大圆扇头饰，实脸）
- 风格：`shadow`（戏台上的透光皮影）、`color`（摄像头画面上挂在手指上的彩绘小人）
- 部件：`torso` `head` `skirt` `upperArm` `forearm` `leg` `paddle` `sword` `tongue`

修改 manifest 后刷新页面即可（`loadPuppetArt()` 在启动时读取一次）。

## 出图规范

**朝向**：一律画成 **面朝右** 的侧面剪影。电脑角色在戏台上面朝左，由 rig 水平镜像，不要单独画镜像版。

**分辨率**：1 个世界单位 = 2 像素（`s = 0.5`）。整个皮影站立时约 700 世界单位高（含头饰）= 1400 像素。
用更高分辨率也可以，比如 3 倍就填 `s = 0.3333`，`ox/oy` 按实际像素给。

**格式**：PNG-32，透明背景。`shadow` 风格的镂空处要真正透明（alpha=0），半透光的皮面用 alpha 0.5–0.9，
背后戏台的暖光会从镂空处透出来；`color` 风格可以不透明，镂空处同样透明。

**枢轴与静止朝向**（尺寸为世界单位，见 `src/puppet/skeleton.js` 的 `SK`；`+y` 向下）：

| 部件 | 枢轴（关节） | 静止朝向 / 名义尺寸 |
|---|---|---|
| `torso` | 骨盆 | 向上延伸到脖子 `(4,-200)`；上宽 92、下宽 70。肩：前 `(12,-182)`，后 `(-6,-184)` |
| `head` | 脖子 | 向上，含头饰，头顶提线挂点 `(0,-150)`；脸宽约 80；**嘴 `(40,-42)`** 是舌头的枢轴，嘴要张开能伸出舌头 |
| `skirt` | 骨盆 | 向下张开，名义长 170、上宽 110、下宽 170（代码版加长到约 240 盖住小腿） |
| `upperArm` | 肩 | 沿 `+y` 下垂，肘在 `(0,120)`，宽 26 |
| `forearm` | 肘 | 沿 `+y`，腕在 `(0,110)`，腕下约 22 画握拳的手，宽 22 |
| `leg` | 髋 | 沿 `+y` 到脚踝 `(0,330)`，宽 30，靴尖朝 `+x` 约 46，靴底在约 `y=355` |
| `paddle` | 握点（腕） | 沿 `+y`：柄 0..24，拍面圆心 `(0,52)`，半径 30（`PADDLE_R`） |
| `sword` | 握点（腕） | 沿 `+y`：剑格约 18，剑尖 `(0,210)`；剑穗挂在 `-y` 方向的柄尾 |
| `tongue` | 嘴 | 沿 `+x` 前伸约 46（可向下耷拉、舌尖略卷） |

**关节处要重叠**：每节肢体在枢轴处画一个圆头（半径约为肢宽的一半），末端也画圆头，
这样相邻两节绕关节转动时不会露缝。前后两侧肢体共用同一张图（rig 会给后侧压暗）。

**可以超出名义宽度**：衣袖、飘带、翎子、袍摆都可以画到名义尺寸外，只要枢轴准确。

## 代码绘制版的尺寸（可直接当模板）

下表是代码绘制的贴图像素尺寸和枢轴（2 倍分辨率，`s = 0.5`），按同样的画布大小和枢轴出图最省事：

| 部件 | hero | rival |
|---|---|---|
| `torso` | 276×460，枢轴 (132, 432) | 同左 |
| `head` | 456×676，枢轴 (336, 640) | 384×464，枢轴 (260, 428) |
| `skirt` | 680×532，枢轴 (388, 32) | 同左 |
| `upperArm` | 96×312，枢轴 (48, 40) | 同左 |
| `forearm` | 72×308，枢轴 (36, 32) | 同左 |
| `leg` | 184×760，枢轴 (48, 36) | 同左 |
| `paddle` | 132×190，枢轴 (66, 20) | 同左 |
| `sword` | 76×540，枢轴 (40, 112) | 同左 |
| `tongue` | 126×96，枢轴 (10, 20) | 同左 |

导出代码版当底稿：在浏览器控制台运行

```js
const { getPart } = await import('/src/puppet/art.js');
const p = getPart('hero', 'shadow', 'torso');
p.img.toBlob((b) => open(URL.createObjectURL(b)));
```

## 自检

`tests/art.html` 可以直接看效果（需要本地静态服务，如 `start.bat`）：

- `?view=grid`：全部部件 + 枢轴十字（青）+ 名义长度线（洋红）。换图后先看这里，枢轴十字要落在关节上
- `?view=stage` / `?view=color`：拼成完整皮影的戏台效果 / 彩绘效果
- `?view=joints`：各种肘角、髋角下看关节有没有缝
- `?view=override`：PNG 覆盖机制自测（用 `tests/stubs/art_manifest.json`）
